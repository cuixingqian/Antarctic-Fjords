# Dataset Description

This repository contains:
- An Excel file with compiled and newly generated data
- Matlab scripts for Monte Carlo resampling
- A LICENSE file

## File Structure
- data.xlsx: main dataset
- script.m: Monte Carlo resampling script

## Notes
- Column descriptions are provided within each worksheet
- All OC values are reported as wt% on a dry-sediment basis

## Correspondence with manuscript
The datasets correspond to figures and tables in the manuscript.
